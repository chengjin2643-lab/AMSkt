# Distribution and attribution

This repository contains a selected subset of the AMSkt research implementation.

No project-wide open-source license has been assigned. The authors must approve a software license before an open-source release. The repository's public or private visibility is separate from licensing.

The selected C++ engine uses the standard library. No MurmurHash3 implementation, external dataset or dependency source is redistributed in this subset. Original source and attribution comments, where present, are retained. Toolchains and libraries used to build the code remain subject to their own licenses.

The experiment runner includes optional entry points for locally prepared real inputs, but no real input files are supplied. This repository grants no rights to redistribute PSID, NLSY79, KASANDR or other provider data.
